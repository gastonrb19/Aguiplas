# Aguiplas

Sitio web de Aguiplas construido con HTML, CSS, módulos ES y Web Components nativos, sin framework ni proceso de build.

## Desarrollo local

Sirve el directorio raíz mediante HTTP para que el navegador cargue los módulos ES:

```sh
python3 -m http.server 8000
```

Abre <http://localhost:8000>. Las fotografías y recursos visuales se cargan desde los orígenes públicos de la propuesta de diseño.
